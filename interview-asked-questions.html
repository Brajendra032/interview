Question 1 SQL
Get employee list where employee salary > manager salary
Table Structure:
employees(id, name, manager_id, salary)
✅ Query:
SELECT e.name AS EmployeeName, e.salary AS EmployeeSalary, m.name AS ManagerName, m.salary AS ManagerSalary FROM employees e JOIN employees m ON e.manager_id = m.id WHERE e.salary > m.salary;
💡 Explanation:
We are joining the employee table with itself (self-join).
Then, we compare the employee's salary with their manager's salary.
Question 2 Algorithm PHP
Group Anagrams
Input:
["eat", "tea", "tan", "ate", "nat", "bat"]
Output:
[ ["eat", "tea", "ate"], ["tan", "nat"], ["bat"] ]
✅ Solution:
<?php $words = ["eat", "tea", "tan", "ate", "nat", "bat"]; function groupAnagrams($words) { $map = []; foreach ($words as $word) { // Sort each word alphabetically — this will be the grouping key $key = str_split($word); sort($key); $key = implode('', $key); // Add word to its anagram group $map[$key][] = $word; } // Re-index the array (to remove associative keys) return array_values($map); } $result = groupAnagrams($words); print_r($result); ?>
💡 Easy explanation:
If two words have the same sorted letters → they are anagrams.
So we group them by that key.
Question 3 Threading
Can we use multiple threads inside a thread?
✅ Answer:
Yes, we can create multiple threads inside a thread.
A thread is just like a function — it can start more threads.
💡 Example (Java):
class MyThread extends Thread { public void run() { new Thread(() -> System.out.println("Inner thread")).start(); } }
So yes — one thread can start other threads (called nested threads).
Question 4 Laravel
What is hasMany and belongsToMany in Laravel?
✅ hasMany
→ Used when one model has many related models.

Example: One User has many Posts.
// In User model public function posts() { return $this->hasMany(Post::class); } // In Post model public function user() { return $this->belongsTo(User::class); }
✅ belongsToMany
→ Used for many-to-many relationship (pivot table in between).

Example: A User can belong to many Roles, and a Role can belong to many Users.
// In User model public function roles() { return $this->belongsToMany(Role::class); }
Question 5 Laravel
How to use Many-to-Many in Laravel
✅ Example:
We have 3 tables:
• users
• roles
• role_user (pivot table: user_id, role_id)
// User.php public function roles() { return $this->belongsToMany(Role::class); } // Role.php public function users() { return $this->belongsToMany(User::class); }
Attach or Sync Example:
$user = User::find(1); $user->roles()->attach(2); // add role id 2 $user->roles()->sync([1,2]); // replace with these roles
Question 6 Laravel
How to handle synchronous process in Laravel
✅ Meaning:
Sometimes you want to run tasks one after another (not parallel) — this is synchronous.
Ways to handle:
Use Jobs & Queues: for async,
but for synchronous, you can run code directly without dispatching to queue.
// Normal synchronous call $user = User::find(1); Mail::to($user->email)->send(new WelcomeMail()); // This waits until the mail is sent before continuing. // If you want async: use queue Mail::to($user->email)->queue(new WelcomeMail());
So, synchronous = wait for each step to complete.
Question 7 AWS
Drawback of AWS Lambda
✅ Main Drawbacks:
  • Cold Start: first execution takes time (slow response)
  • Limited Runtime: max 15 mins
  • Limited memory: up to 10 GB
  • Not good for long-running or heavy compute tasks
  • Debugging and monitoring is harder
Question 8 AWS
Can we use Lambda for long-running task?
❌ No, not good for that.
AWS Lambda has a max execution limit of 15 minutes.
For long-running tasks, use:
  • AWS ECS (Elastic Container Service)
  • AWS Batch
  • AWS EC2 instance
Question 9 SQL
2nd / 3rd Highest Salary
✅ Using LIMIT:
SELECT DISTINCT salary FROM employees ORDER BY salary DESC LIMIT 1 OFFSET 1; -- 2nd LIMIT 1 OFFSET 2; -- 3rd
✅ Using Subquery:
SELECT MAX(salary) FROM employees WHERE salary < (SELECT MAX(salary) FROM employees);
✅ Using DENSE_RANK():
SELECT name, salary FROM ( SELECT name, salary, DENSE_RANK() OVER (ORDER BY salary DESC) AS rnk FROM employees ) t WHERE rnk = 2;
Question 10 PHP
PHP Trick — echo "5" + "2days";
✅ Output: 7
👉 PHP converts both to numbers:
  • "5" → 5
  • "2days" → 2
  • So → 5 + 2 = 7
📌 If string starts with letters, becomes 0.
Expression Output "5" + "2days" 7 "5abc" + "10xyz" 15 "abc" + "5" 5
